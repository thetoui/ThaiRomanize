# ThaiRomanize

แปลงอักษรไทยเป็นอักษรโรมันตามหลัก **RTGS** (Royal Thai General System of Transcription) พร้อมเครื่องหมายวรรณยุกต์ — ใช้กฎการอ่านภาษาไทย + การค้นหาวิธีแยกพยางค์ที่เป็นไปได้มากที่สุด + พจนานุกรมคำยกเว้น ไม่มี dependency ไม่ต้องต่อเน็ต ใช้ได้ทั้งบนเบราว์เซอร์และ Node.js

🔗 **Live demo:** https://thai-roman.vercel.app

```
สวัสดีครับ ยินดีที่ได้รู้จัก  →  sà-wàt-di-khráp yin-di-thî-dâi-rú-chàk
```

## คุณสมบัติ

- แปลงอักษรไทยเป็นโรมันตามหลัก RTGS โดยวิเคราะห์พยัญชนะต้น อักษรควบ อักษรนำ สระ ตัวสะกด และวรรณยุกต์ด้วยกฎภาษาศาสตร์
- **ไม่ตัดพยางค์แบบเดาทีละตัว** — ระบบไล่ดูทุกวิธีที่ข้อความอาจแยกพยางค์ได้ (สระที่เขียนชัด, สระอะ/โอะลดรูป, สระหน้าที่เป็นของพยัญชนะตัวที่สองอย่าง เสนอ แสดง, ร หัน, ตัวสะกดที่ไม่ออกเสียง ฯลฯ) แล้วเลือกวิธีที่เป็นไปได้มากที่สุดทั้งข้อความ ความผิดพลาดตรงหนึ่งจึงไม่ลามทั้งคำ
- รู้จักขอบเขตคำจากรายการคำที่พบบ่อย 6,000 คำ (คลังข้อมูลภาษาไทยแห่งชาติ) จึงอ่านข้อความยาวที่ไม่เว้นวรรคได้ถูก เช่น จีบ|ชนิด ไม่กลายเป็น จี-บด-นิด
- พจนานุกรมคำอ่านยกเว้นกว่า 1,000 คำ ที่ไล่ตรวจจากคำที่พบบ่อยที่สุดในภาษาไทยทีละคำ — คำบาลี-สันสกฤตที่มีพยางค์เชื่อม (ราชการ = ราด-ชะ-กาน, คุณภาพ = คุน-นะ-พาบ), ตัวอักษรที่ไม่ออกเสียง, ชื่อจังหวัด ฯลฯ
- คำนวณเสียงวรรณยุกต์ทั้ง 5 เสียง (สามัญ เอก โท ตรี จัตวา) จากหมู่อักษร (สูง/กลาง/ต่ำ) + รูปวรรณยุกต์ + คำเป็น-คำตาย + ความสั้น-ยาวของสระ + อักษรนำ
- รองรับการันต์ (จันทร์ ศาสตร์ ลักษณ์), ร หัน (ธรรม บรรจุ สวรรค์), ฤ ฦ (ฤดู อังกฤษ พฤษภาคม), ร ไม่ออกเสียง (บัตร สมุทร เพชร), สระท้ายที่ไม่ออกเสียง (ชาติ เหตุ ประวัติ)
- รองรับตัวเลขไทย (๐-๙ → 0-9), ไม้ยมก (ๆ ซ้ำทั้งคำ เช่น สบายๆ), ฯลฯ, ข้อความปนภาษาอังกฤษ/ตัวเลข/เครื่องหมายวรรคตอน และแก้การพิมพ์ผิดที่พบบ่อย (เ+เ แทน แ, ํ+า แทน ำ)
- ปรับรูปแบบผลลัพธ์ได้อิสระ: เปิด/ปิดวรรณยุกต์, ตัวคั่นพยางค์ (ติดกัน/เว้นวรรค/ขีดกลาง), ตัวพิมพ์ใหญ่-เล็ก (พิมพ์เล็ก/ต้นประโยคใหญ่/ทุกพยางค์ใหญ่)
- ไม่มี dependency, ไฟล์เดียว (~190KB, ~53KB เมื่อบีบอัด gzip — CDN บีบอัดให้อัตโนมัติ), รองรับทั้ง CommonJS (`require`) และ browser global (`<script>`)

## ติดตั้งใช้งาน

**วิธีที่ 1 — ใช้ผ่าน CDN (เร็วที่สุด ไม่ต้องติดตั้ง)**

```html
<script src="https://cdn.jsdelivr.net/gh/thetoui/ThaiRomanize@main/assets/js/thai-romanize.js"></script>
<script>
  console.log(ThaiRomanizer.romanize('สวัสดี').text); // sà-wàt-di
</script>
```

**วิธีที่ 2 — ติดตั้งผ่าน npm ตรงจาก GitHub (สำหรับโปรเจกต์ Node.js)**

```bash
npm install github:thetoui/ThaiRomanize
```

```js
const ThaiRomanizer = require('thai-romanize');
console.log(ThaiRomanizer.romanize('สวัสดี').text); // sà-wàt-di
```

**วิธีที่ 3 — ดาวน์โหลดไฟล์ไปใช้ตรงๆ**

ก็อปไฟล์ [`assets/js/thai-romanize.js`](assets/js/thai-romanize.js) ไปวางในโปรเจกต์แล้ว `<script src="...">` หรือ `require(...)` ได้เลย ไฟล์เดียวจบ ไม่มี dependency ให้ติดตั้งเพิ่ม

## การใช้งาน (API)

### `ThaiRomanizer.romanize(text, options?)`

แปลงข้อความ (ประโยคหรือคำ ยาวแค่ไหนก็ได้) เป็นอักษรโรมัน คืนค่าเป็น object:

```js
{
  text: string,       // ผลลัพธ์อักษรโรมัน
  syllables: number,  // จำนวนพยางค์ไทยที่แปลงได้
  detail: [           // รายละเอียดต่อคำ สำหรับ debug หรือประมวลผลต่อ
    { thai: 'สวัสดี', syls: [{ r: 'sa', t: 1 }, { r: 'wat', t: 1 }, { r: 'di', t: 0 }] }
  ]
}
```

**Options**

| ตัวเลือก    | ค่าที่รับได้                          | ค่าเริ่มต้น | ความหมาย |
|-------------|----------------------------------------|-------------|----------|
| `tone`      | `true` \| `false`                      | `true`      | ใส่/ไม่ใส่เครื่องหมายวรรณยุกต์ (à, á, â, ǎ) |
| `separator` | `'hyphen'` \| `'space'` \| `'join'`    | `'hyphen'`  | ตัวคั่นระหว่างพยางค์ในคำเดียวกัน |
| `case`      | `'lower'` \| `'sentence'` \| `'title'` | `'lower'`   | รูปแบบตัวพิมพ์ใหญ่-เล็ก |
| `mode`      | `'tones'` \| `'segmented'` \| `'plain'`| `'tones'`   | ทางลัดตั้งค่าทั้งสามข้างบนพร้อมกัน (ใช้แทน `tone`/`separator`/`case` ก็ได้ ถ้าไม่ต้องการความละเอียด) |

`tone` / `separator` / `case` เขียนพร้อมกันได้อิสระและมีผลเหนือค่าที่ `mode` ตั้งไว้เสมอ

**ตัวอย่างผลลัพธ์ทั้งหมดจาก "สวัสดี"**

```js
ThaiRomanizer.romanize('สวัสดี', { tone: false, separator: 'join',   case: 'lower'    }).text; // "sawatdi"
ThaiRomanizer.romanize('สวัสดี', { tone: false, separator: 'join',   case: 'sentence' }).text; // "Sawatdi"
ThaiRomanizer.romanize('สวัสดี', { tone: false, separator: 'join',   case: 'title'    }).text; // "SaWatDi"
ThaiRomanizer.romanize('สวัสดี', { tone: false, separator: 'space',  case: 'lower'    }).text; // "sa wat di"
ThaiRomanizer.romanize('สวัสดี', { tone: false, separator: 'space',  case: 'sentence' }).text; // "Sa wat di"
ThaiRomanizer.romanize('สวัสดี', { tone: false, separator: 'space',  case: 'title'    }).text; // "Sa Wat Di"
ThaiRomanizer.romanize('สวัสดี', { tone: false, separator: 'hyphen', case: 'lower'    }).text; // "sa-wat-di"
ThaiRomanizer.romanize('สวัสดี', { tone: false, separator: 'hyphen', case: 'sentence' }).text; // "Sa-wat-di"
ThaiRomanizer.romanize('สวัสดี', { tone: false, separator: 'hyphen', case: 'title'    }).text; // "Sa-Wat-Di"

ThaiRomanizer.romanize('สวัสดี').text;                       // "sà-wàt-di"   (ค่าเริ่มต้น: มีวรรณยุกต์)
ThaiRomanizer.romanize('สวัสดี', { mode: 'plain' }).text;     // "sawatdi"     (RTGS มาตรฐาน ไม่มีวรรณยุกต์ ไม่มีขีดคั่น)
```

ข้อความที่มีภาษาอังกฤษ ตัวเลข หรือเครื่องหมายวรรคตอนปนอยู่จะถูกคงไว้ตามเดิม ไม่ถูกแปลง:

```js
ThaiRomanizer.romanize('Hello สวัสดี World 123').text; // "Hello sà-wàt-di World 123"
```

### `ThaiRomanizer.romanizeWord(word)`

แปลงคำเดียวแบบ low-level คืนค่าเป็น array ของพยางค์ `{ r, t, cls }` (r = เสียงโรมัน, t = เลขวรรณยุกต์ 0-4, cls = หมู่อักษร) โดยไม่ผ่านการจัดรูปแบบ (tone mark / separator / case) — ใช้ตอนต้องการประมวลผลระดับพยางค์เอง

### `ThaiRomanizer.applyTone(roman, tone)`

ใส่เครื่องหมายวรรณยุกต์ให้พยางค์โรมัน 1 พยางค์ เช่น `applyTone('a', 1)` → `'à'`

### ค่าคงที่

- `TONE_NAMES_EN` — `['mid', 'low', 'falling', 'high', 'rising']`
- `TONE_NAMES_TH` — `['สามัญ', 'เอก', 'โท', 'ตรี', 'จัตวา']`
- `version`

## ความแม่นยำ

วัดจากคำที่พบบ่อยที่สุดในคลังข้อมูลภาษาไทยแห่งชาติ (TNC) โดยเทียบคำอ่านทั้งคำ (ทุกพยางค์ + วรรณยุกต์ต้องตรง) กับคำอ่านอ้างอิงจาก [TLTK](https://pypi.org/project/tltk/) ของจุฬาลงกรณ์มหาวิทยาลัย แล้วตรวจคำที่ไม่ตรงกันทีละคำด้วยมือ (คำอ่านอ้างอิงเองก็ผิดบ้าง เช่น แผล แปร ภูมิใจ — ตัวเลขด้านล่างนับตามคำอ่านอ้างอิง จึงต่ำกว่าความแม่นยำจริงเล็กน้อย)

| ชุดคำ (อันดับความถี่) | v1.0 | v1.1 |
|---|---|---|
| 6,000 คำแรก | 85.3% | **98.3%** |
| 6,000 คำแรก ถ่วงตามความถี่ที่ใช้จริง | 95.0% | **99.7%** |
| อันดับ 6,000–13,000 | 80.7% | **94.8%** |
| อันดับ 13,000–20,000 | 78.5% | **91.4%** |
| อันดับ 20,000–27,000 (ไม่ได้ใช้ปรับระบบเลย) | HOLDOUT_OLD | **HOLDOUT_NEW** |
| วลี 3–6 คำพิมพ์ติดกัน (คำที่อ่านถูกเมื่อแยกเดี่ยว) | 92.6% | **99.1%** |

## ข้อจำกัด

- คำพ้องรูปที่อ่านต่างกันตามความหมาย (เช่น เพลา, สระ) ระบบเลือกคำอ่านที่พบบ่อยกว่า
- คำบาลี-สันสกฤตที่มีพยางค์เชื่อม (ราชการ, ภาพยนตร์) ไม่มีกฎตายตัว ต้องอาศัยพจนานุกรม — คำที่ไม่ค่อยพบและยังไม่อยู่ในพจนานุกรมอาจอ่านแบบไม่มีพยางค์เชื่อม
- คำยืมภาษาอังกฤษ วรรณยุกต์ที่ได้เป็นไปตามกฎการเขียน ซึ่งอาจต่างจากเสียงที่พูดจริงบ้าง (คำที่พบบ่อยอย่าง คอมพิวเตอร์ แก้ไว้แล้ว)
- ผลลัพธ์ยังคั่นพยางค์ทั้งช่วงข้อความไทยที่ติดกัน ไม่ได้เว้นวรรคระหว่างคำ

หากพบคำที่แปลงผิด เพิ่มคำอ่านที่ถูกลงใน [`scripts/data/exceptions.tsv`](scripts/data/exceptions.tsv) (ดูหัวข้อถัดไป) หรือเปิด issue ได้เลย

## พัฒนาต่อ / เพิ่มคำยกเว้น

```bash
npm test          # ทดสอบ (node:test ไม่ต้องติดตั้งอะไรเพิ่ม)
npm run build     # เขียน scripts/data/*.{tsv,txt} ลงใน assets/js/thai-romanize.js
```

- **`scripts/data/exceptions.tsv`** — คำอ่านยกเว้น บรรทัดละคำ `คำ<TAB>คำอ่าน` เช่น `ราชการ	rat2-cha3-kan0` (พยางค์คั่นด้วย `-` แต่ละพยางค์ลงท้ายด้วยเลขวรรณยุกต์ 0 สามัญ, 1 เอก, 2 โท, 3 ตรี, 4 จัตวา) คำที่ลงท้ายด้วย `-` เป็นคำนำหน้าที่ใช้เฉพาะเมื่อมีพยางค์ตามมา เช่น `ราช-	rat2-cha3` ทำให้ ราชการ = ราด-ชะ-กาน แต่ มหาราช ยังเป็น ราด
- **`scripts/data/words.txt`** — รายการคำที่พบบ่อย ใช้บอกขอบเขตคำเท่านั้น (คำอ่านยังมาจากกฎ) สร้างใหม่ได้จากไฟล์ความถี่คำใดๆ ด้วย `node scripts/build-data.js --words-from tnc_freq.txt 6000`
- **`tests/cases.js`** — คำอ่านที่คาดหวังแยกตามกฎ ใช้ตรวจว่าการแก้ไขไม่ทำให้คำอื่นเพี้ยน

```

assets/js/app.js             โค้ดเชื่อม UI ↔ engine ของหน้าเว็บ

tests/                       ชุดทดสอบ (npm test)
```
